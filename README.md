# AI Ask

여러 AI에게 한 번에 물어보는 맥 앱. 두 가지 모드가 있어요.

- **모드 1 · 4개 AI 동시** — 8개 모델 중 4개를 골라 창 4개를 띄우고, 같은 질문을 한 번에 보냅니다.
- **모드 2 · 같은 AI 4개 (독립)** — AI 하나를 골라 그 AI 창만 4개를 띄웁니다. 각 창을 따로 씁니다.

지원 모델(8개): Notion AI · Gemini · ChatGPT · Claude · Perplexity · Grok · Genspark · AI Studio

## 앱으로 설치 (일반 사용자)

1. `AI Ask-x.x.x-arm64.dmg` 파일을 받아서 엽니다.
2. **AI Ask.app**을 응용 프로그램 폴더로 드래그합니다.
3. 서명되지 않은 앱이라 처음 열 때 보안 경고가 뜹니다.
   시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 **"그래도 열기"**를 한 번 눌러주면 그 뒤로는 정상 실행됩니다.

필요 환경: 애플 실리콘 맥(M1 이상) + Google Chrome 설치. 앱이 크롬 창을 직접 열어서 동작합니다.

## 소스로 실행 (개발자)

- Node.js 18+ (https://nodejs.org), pnpm (`npm install -g pnpm`)

```bash
git clone https://github.com/orot-ai/ai-ask.git
cd ai-ask
pnpm install
pnpm start
```

앱(DMG) 빌드는 `pnpm dist` → `dist/` 안에 `AI Ask.app`과 DMG가 생깁니다.

## 최초 로그인

버튼을 눌러 크롬 창이 뜨면 **각 창에서 본인 계정으로 로그인**하세요. 로그인 세션은 내 PC(`~/.ai-ask/profile/`)에만 저장되고, 다음부터는 자동 로그인됩니다. 두 모드가 같은 로그인을 공유합니다.

## 사용법

### 모니터 선택

버튼 창 위쪽의 **"기본 설정 (주 모니터에 열기)"** 체크를 끄면 모니터 배치도가 펼쳐집니다.
원하는 모니터를 클릭하면 크롬 창 4개가 그 모니터에 배치됩니다.

### 모드 1 · 4개 AI 동시 (왼쪽부터 선택)

1~4번 자리마다 드롭다운으로 모델을 고릅니다. 왼쪽 창부터 1→4번 순서로 배치돼요.
이미 다른 자리에 있는 모델을 고르면 두 자리가 맞바꿔집니다(중복 없음). 선택한 순서는 저장되어 다음 실행에도 유지됩니다.

"4개 AI 띄우기" 버튼 → 선택한 4개 모델 창이 뜹니다.
아무 곳에서나 `!`로 시작하는 텍스트를 **복사(Cmd+C)** 하면 4개 AI에 동시 전송됩니다.

```
!봄에 대한 시 써줘
!이 에러 메시지 뭔지 설명해줘
```

`!!` 만 복사하면 4개 AI의 마지막 답변을 모아 클립보드에 복사합니다.
`!` 없이 복사하면 아무 일도 안 일어나니 안심하세요.

**AI 링크 모음 복사 → 대화방 자동 이동**: 서로 다른 AI의 채팅 링크가 2개 이상 들어 있는
텍스트를 복사하면(예: 노션에 모아둔 링크 블록), 열려 있는 각 AI 창이 해당 주소로 이동합니다.
이후 `!질문`은 그 대화방으로 이어서 전송돼요. 링크 1개짜리 일반 복사에는 반응하지 않습니다.

### 모드 2 · 같은 AI 4개 (독립)

8개 모델 버튼 중 하나 → 그 AI 창 4개가 뜹니다.
이 모드는 **자동 전송·수집이 없어요.** 각 창에 직접 입력해 따로따로 씁니다.
현재 열려 있는 AI 버튼은 녹색으로 표시됩니다.

## 실행 중에 AI 버튼 = 탭 열기 + 전환

실행 중에도 버튼이 잠기지 않아요. 모델 버튼을 누르면:

- 그 AI 탭이 **아직 없는 창엔 새 탭으로 열고**,
- **이미 열려 있으면 그 탭을 맨 앞으로** 가져와요.

결과적으로 **4개 창이 전부 그 AI 화면으로 정렬**됩니다. 그래서 Gemini를 누르면 4창 모두 Gemini, ChatGPT를 누르면 4창 모두 ChatGPT로 한 번에 전환돼요. (새 버튼 없이 기존 버튼이 "열기 겸 전환" 역할)

"4개 AI 띄우기"를 실행 중에 다시 누르면 각 창의 원래 첫 탭(선택한 4개 모델)이 앞으로 나옵니다.
`!질문` 자동 전송/수집은 처음 띄운 첫 탭 4개에만 적용돼요.
"닫기"를 누르면 그 세션의 크롬 창이 모두 정리됩니다.

## 종료

버튼 창의 "종료/닫기"를 누르거나 버튼 창을 닫으면 크롬 창까지 정리됩니다.

## 터미널로만 쓰기 (선택)

GUI 없이 모드 1만 바로 쓰고 싶으면:

```bash
pnpm cli    # = node browser.mjs
```

## 데이터 저장 위치

- `~/.ai-ask/profile/` — 브라우저 프로필 (로그인 세션, 개인 PC에만 저장)

> 로그인 정보는 각자의 PC에만 저장되며 Git에 올라가지 않습니다.
